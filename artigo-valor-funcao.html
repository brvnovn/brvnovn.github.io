Valor = Função

Subtítulo em uma linha, definido junto com o texto final

Contexto

Parágrafo de exemplo, presente aqui para conferir a medida de linha, a entrelinha e o contraste do corpo de 14px dentro da coluna de 584px. O texto definitivo entra no lugar deste bloco sem alterar a marcação ao redor.

Segundo parágrafo, para verificar o espaço entre blocos de texto corrido. Um link no meio da frase aparece sublinhado, para se distinguir do texto mesmo quando a cor não basta.

A hipótese

Enunciado curto do que o estudo de caso pretende demonstrar, seguido dos pontos que o sustentam.

  • Primeiro item da lista sem numeração, com o texto alinhado à margem da coluna.
  • Segundo item, um pouco mais longo, para ver como a quebra de linha se comporta quando o texto passa de uma única linha dentro do item.
  • Terceiro item.

Como foi medido

Parágrafo que apresenta o método antes de detalhar cada parte dele.

Critérios

Subseção usada para separar as partes dentro de um mesmo bloco, sem criar uma seção nova.

Comparação

Segunda subseção, para confirmar o respiro entre uma subseção e a anterior.

Decisões de projeto

Quando a ordem das decisões importa, a lista é numerada.

  1. Primeira decisão, com a justificativa que a sustenta.
  2. Segunda decisão, também com uma frase de justificativa logo em seguida para manter o padrão.
  3. Terceira decisão.

Resultado

Fechamento do estudo de caso: o que mudou depois das decisões acima.

Citação ou destaque, para trechos de entrevista, falas de usuários e frases que valem ser lidas fora do corpo do texto.
